# HydraXAI: Data Dictionary & Metadata Audit

This document provides a comprehensive technical audit of the datasets utilized in the HydraXAI framework. This dictionary serves as the ground-truth reference for all subsequent machine learning experiments and ensures the reproducibility of the study.

## Metadata Specifications
* **Study Region:** Konkan and Western Ghats, India.
* **Temporal Resolution:** 2010–2025.
* **Spatial Resolution:** 30m Grid.
* **Coordinate Reference System (CRS):** EPSG:4326 (WGS84).
